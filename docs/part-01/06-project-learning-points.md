# 第一部分综合项目：学习积分结算器

## 项目背景

某学习活动按照以下方式记录积分：

- 学生连续 4 天分别获得一些积分；
- 每累计 10 分可以兑换 1 枚徽章；
- 不足 10 分的部分保留为剩余积分；
- 最后输出总积分、徽章数、剩余积分和每天平均积分。

## 输入格式

输入 4 个非负整数，表示连续 4 天获得的积分。每个整数都不超过 `1000`。

## 输出格式

共输出 4 行：

1. 总积分；
2. 可兑换的徽章数；
3. 剩余积分；
4. 每天平均积分，保留两位小数。

## 样例输入

```text
8 12 15 9
```

## 样例输出

```text
44
4
4
11.00
```

## 解题任务单

先不要急着看参考程序，请填写：

```text
输入的数据：____________________________

需要的变量及类型：______________________

总积分公式：____________________________

徽章数公式：____________________________

剩余积分公式：__________________________

平均积分公式：__________________________
```

## 参考程序

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int day1, day2, day3, day4;
    cin >> day1 >> day2 >> day3 >> day4;

    int total = 0;
    total += day1;
    total += day2;
    total += day3;
    total += day4;

    int badges = total / 10;
    int remaining = total % 10;
    double average = total / 4.0;

    cout << total << '\n';
    cout << badges << '\n';
    cout << remaining << '\n';
    cout << fixed << setprecision(2) << average << '\n';
    return 0;
}
```

## 项目验收

请至少测试下面 4 组数据，并先手算答案：

1. `8 12 15 9`：普通情况；
2. `0 0 0 0`：全部为 0；
3. `10 10 10 10`：没有剩余积分；
4. `1 2 3 4`：总分正好为 10。

能解释每一行代码，并能在不看参考程序的情况下重新写出，才算真正完成项目。
