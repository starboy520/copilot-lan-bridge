# 第一部分：走进 C++ 与信息学竞赛

适合 13 岁左右、C++ 零基础的学习者。建议用 12～15 个课时完成。

## 完成目标

学完后，孩子应当能够：

- 独立创建、运行和修改简单 C++ 程序
- 理解 OI 中的输入、处理、输出和评测
- 根据数据选择基础数据类型
- 按题目要求控制空格、换行和小数位数
- 使用计数器和累加器更新数据
- 使用整数除法和取余解决分组、时间与数位问题
- 独立完成第一部分综合项目
