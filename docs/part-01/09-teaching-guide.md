# 给家长或老师的使用建议

1. 不要要求孩子一次读完。每课只引入一个核心概念，并留出亲手写代码的时间。
2. 每个例题先遮住代码，让孩子说出“输入—处理—输出”。
3. 代码报错时，不直接指出答案；先让她从第一条错误信息、标点和变量名开始检查。
4. 每道例题至少改造一次，例如改变输入数量、输出格式或生活情境。
5. 如果连续两节课独立完成率低于一半，应降低题目难度，而不是加快讲解。
6. 如果孩子能独立完成闯关标准，再进入下一章；不以固定日期强行赶进度。
7. 本部分不提前讲条件和循环，避免孩子同时承担过多新概念；后续课程学到循环后，再回来改写累加器程序。
8. 第 2 章的二进制内容属于选学。先用四盏灯帮助孩子理解，不要求背转换方法；补码、位运算和进制转换算法留到后续课程。

## 新符号出现顺序

零基础教材最容易让孩子卡住的，不一定是算法，而是突然出现、没有解释的小符号。辅导时请保持下面的顺序：

| 首次正式学习 | 新内容 | 此前怎样处理 |
|---|---|---|
| 第 1 章 | `#include <bits/stdc++.h>`、`cout`、`cin`、`endl`、`;`、`//` | 把 `bits/stdc++.h` 理解为学校竞赛环境中的“常用工具总包”；`endl` 只按“换行”的固定写法使用 |
| 第 2 章字符部分 | `char`、单引号、`\n` | 在讲清字符前，示例不提前使用 `\n` |
| 第 3 章 | `scanf`、`printf`、格式符、输入变量前的 `&`、`%.2f`、`%02d`；选学 `static_cast<double>` | 先把格式符理解成数据的“座位牌”；强调输入 `double` 用 `%lf`，输出用 `%f`；类型转换只要求能读懂，不扩展其他写法 |
| 第 4 章 | `+=`、`++` 与计数器、累加器 | 先写完整的 `x = x + 1`，再学习简写 |
| 第 5 章 | 整数除法 `/`、取余 `%` 的完整规则 | 数位拆分优先保留括号，如 `(n / 10) % 10` |

如果孩子不能解释某个符号，应当先回到它第一次正式出现的位置，不要求她把未讲过的写法直接背下来。

## 第一次上机陪学清单

第一章结束前，让孩子亲手完成以下动作，家长或老师只在卡住时提示：

1. 自己新建并保存一个 `.cpp` 文件；
2. 找到“编译”和“运行”按钮，知道二者不是同一件事；
3. 根据第一条报错信息修复一次漏分号或大小写错误；
4. 在需要输入的程序中，自己输入一组数据并查看输出；
5. 除样例外，再设计至少两组测试数据并先手算答案；
6. 在题面中指出题目描述、输入格式、输出格式、数据范围和样例。

不同学校的软件界面不一样，不要求孩子背按钮位置；重点是理解“保存源代码—编译—运行—测试”的过程。

## 建议课时安排

| 课时 | 内容 | 课后成果 |
|---:|---|---|
| 1 | 程序、OI、第一次运行 | 输出自己的第一段文字 |
| 2 | 程序结构、计算、注释 | 完成简单计算程序 |
| 3 | OI 输入输出与评测 | 完成两数之和、长方形面积 |
| 4 | 变量、赋值、变量名 | 能手工跟踪变量变化 |
| 5 | `int`、`long long`、溢出；二进制直觉（选学） | 会按范围选择整数类型，能用四盏灯读懂简单二进制 |
| 6 | `double`、`char`、`string` | 完成个人信息小程序 |
| 7 | `scanf`、`printf` 与格式符 | 正确匹配格式符、变量和 `&` |
| 8 | 小数位数、整数宽度、混合运算与平均数 | 能解释 `5 / 2`、`5 / 2.0` 和 `static_cast<double>(5) / 2` 的区别，完成购物小票和电子钟程序 |
| 9 | 计数器 | 统计事件发生次数 |
| 10 | 累加器 | 完成阅读或步数统计 |
| 11 | 整数除法与取余 | 完成分组问题 |
| 12 | 时间转换与数位拆分 | 完成两个综合例题 |
| 13 | 第一部分综合项目 | 独立完成积分结算器 |
| 14～15 | 订正、补弱与闯关 | 不看资料重写核心程序 |
