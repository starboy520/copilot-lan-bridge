# 第 5 章 整数与取余

## 5.1 整数除法

生活中有这样的问题：17 颗糖平均装进每袋 5 颗，可以装满几袋，还剩几颗？

数学上可以写成：

```text
17 = 5 × 3 + 2
```

其中：

- `3` 是商，表示装满 3 袋；
- `2` 是余数，表示剩下 2 颗。

C++ 中：

```cpp
cout << 17 / 5 << '\n';   // 输出 3
cout << 17 % 5 << '\n';   // 输出 2
```

对非负整数 `a` 和正整数 `b`：

- `a / b` 得到整数商；
- `a % b` 得到余数。

当两个数都是整数时，`/` 的结果仍是整数，小数部分会直接舍去：

```cpp
7 / 2    // 结果为 3，不是 3.5
```

`%` 读作“取余”或“模”。

---

## 5.2 整除关系

如果 `a % b` 的结果是 `0`，说明 `a` 除以 `b` 没有余数，也就是 `a` 能被 `b` 整除。

```cpp
12 % 3   // 0，12 能被 3 整除
14 % 3   // 2，14 不能被 3 整除
```

### 判断奇偶的准备

一个整数除以 2：

- 余数为 0，它是偶数；
- 余数为 1，它是奇数（这里先讨论非负整数）。

下面的程序输出一个非负整数除以 2 的余数：

```cpp
int n;
cin >> n;
cout << n % 2 << '\n';
```

输入 `18`，输出 `0`；输入 `13`，输出 `1`。

以后学习 `if` 后，就能让程序直接输出“奇数”或“偶数”。

## 5.3 应用一：平均分组

### 题目

有 `n` 名同学，每组安排 `k` 人。输出可以安排的完整小组数和剩余人数。

题目保证 `n` 是非负整数，`k` 是正整数，因此不会出现除数为 0。

#### 样例输入

```text
29 6
```

#### 样例输出

```text
4 5
```

### 分析

```text
完整小组数 = n / k
剩余人数   = n % k
```

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;
    cin >> n >> k;
    cout << n / k << ' ' << n % k << '\n';
    return 0;
}
```

### 检查结果

```text
6 × 4 + 5 = 29
```

余数必须满足：

```text
0 ≤ 余数 < 除数
```

如果得到的余数大于或等于 `k`，一定算错了。

## 5.4 应用二：秒数转换

### 题目

输入一个非负整数，表示总秒数，将它转换成“分钟 秒”的形式。

输入：

```text
135
```

输出：

```text
2 15
```

### 分析

一分钟有 60 秒：

```text
分钟数 = 总秒数 / 60
剩余秒数 = 总秒数 % 60
```

### 程序

```cpp
int totalSeconds;
cin >> totalSeconds;

int minutes = totalSeconds / 60;
int seconds = totalSeconds % 60;

cout << minutes << ' ' << seconds << '\n';
```

### 扩展：转换成时、分、秒

输入 `3665` 秒：

```text
小时 = 3665 / 3600 = 1
去掉完整小时后剩下 = 3665 % 3600 = 65 秒
分钟 = 65 / 60 = 1
秒 = 65 % 60 = 5
```

代码：

```cpp
int totalSeconds;
cin >> totalSeconds;

int hours = totalSeconds / 3600;
int remaining = totalSeconds % 3600;
int minutes = remaining / 60;
int seconds = remaining % 60;

cout << hours << ' ' << minutes << ' ' << seconds << '\n';
```

## 5.5 应用三：拆分一个整数的数位

对于三位数 `abc`，例如 `572`：

- 百位是 `5`；
- 十位是 `7`；
- 个位是 `2`。

### 个位

除以 10 的余数就是个位：

```cpp
572 % 10       // 2
```

### 十位

先用整数除法去掉个位，再对 10 取余：

```cpp
572 / 10       // 57
57 % 10        // 7
```

合在一起：

```cpp
(572 / 10) % 10
```

### 百位

```cpp
572 / 100      // 5
```

### 完整程序

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    int hundreds = n / 100;
    int tens = (n / 10) % 10;
    int ones = n % 10;

    cout << hundreds << ' ' << tens << ' ' << ones << '\n';
    return 0;
}
```

输入：

```text
572
```

输出：

```text
5 7 2
```

### 为什么有些代码没有写括号

`/` 和 `%` 的优先级相同，按从左到右计算，所以：

```cpp
n / 10 % 10
```

等价于：

```cpp
(n / 10) % 10
```

两种写法结果相同。但初学时建议保留括号，清楚地表示“先除以 10，再取余”。清楚比少写两个符号更重要。

## 5.6 应用四：周期循环

星期、钟表、轮流报数都具有周期性。取余可以把不断增大的数限制在一个固定范围中。

例如从编号 `0、1、2、3` 中循环选择：

| 原来的数 | 对 4 取余 | 得到的编号 |
|---:|---:|---:|
| 0 | 0 | 0 |
| 1 | 1 | 1 |
| 2 | 2 | 2 |
| 3 | 3 | 3 |
| 4 | 0 | 0 |
| 5 | 1 | 1 |
| 6 | 2 | 2 |

所以 `n % 4` 的结果一定在 `0、1、2、3` 中。

### 例题：星期几

今天是星期一。`n` 天后是星期几？如果用数字 `1～7` 表示星期一到星期日，可以先把今天保存为 `1`：

```cpp
int today = 1;
int answer = (today - 1 + n) % 7 + 1;
```

为什么有“减 1，再加 1”？

取余最方便处理的范围是 `0～6`，而题目使用 `1～7`。因此：

1. 先把星期编号从 `1～7` 移到 `0～6`；
2. 做加法和取余；
3. 再移回 `1～7`。

这是以后循环编号问题中常见的小技巧。

## 5.7 常见错误

### 错误 1：把整数除法当成小数除法

```cpp
int average = 5 / 2;   // 得到 2
```

如果需要 `2.5`：

```cpp
double average = 5 / 2.0;
```

### 错误 2：除数为 0

```cpp
int x = 10 / 0;   // 错误
int y = 10 % 0;   // 错误
```

除法和取余的除数都不能为 0。

### 错误 3：混淆商和余数

```cpp
17 / 5   // 3，完整装了几组
17 % 5   // 2，还剩多少
```

遇到混淆时，回到：

```text
被除数 = 除数 × 商 + 余数
```

### 错误 4：数位顺序写反

个位通常用 `% 10`，去掉个位通常用 `/ 10`。建议用具体数字在纸上逐步验证。

## 第 5 章练习

### 基础练习 1：写出结果

不运行程序，先写出：

1. `23 / 5`
2. `23 % 5`
3. `40 / 8`
4. `40 % 8`
5. `7 / 10`
6. `7 % 10`

### 基础练习 2：装盒子

有 `n` 个苹果，每盒装 `8` 个。输出装满的盒数和剩余苹果数。

### 提高练习 3：时间转换

输入总分钟数，输出“小时 分钟”。例如输入 `150`，输出 `2 30`。

### 提高练习 4：两位数反转

输入一个两位正整数，把它的个位和十位交换后输出。例如输入 `37`，输出 `73`。

提示：

```text
十位 = n / 10
个位 = n % 10
新数 = 个位 × 10 + 十位
```

### 挑战练习 5：四位数数位和

输入一个四位正整数，输出四个数位之和。例如输入 `2026`，输出 `10`。

### 挑战练习 6：时钟推进

现在是 `h` 时 `m` 分，经过 `x` 分钟后是几时几分？使用 24 小时制。保证 `0 ≤ h < 24`、`0 ≤ m < 60`、`0 ≤ x ≤ 1000000000`。

提示：先把当前时间全部换成分钟，再加上 `x`，最后使用 `/` 和 `%` 转回来；小时还需要对 24 取余。
