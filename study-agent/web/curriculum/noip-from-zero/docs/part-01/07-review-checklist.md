## 我学会的 C++ 工具

下面是帮助回忆的“语法卡片”，每一行只展示一种写法，不是可以直接复制运行的完整程序。

cin >> variable;
cout << value << '\n';

scanf("%d", &x);

## 我应该能回答的问题

1. 一个简单程序通常经历哪三个步骤？
2. OI 中算法和 C++ 分别起什么作用？
3. `int` 和 `long long` 应该怎样选择？
4. （选学）`1101`（二进制）为什么等于十进制的 `13`？`bit` 和 `byte` 有什么关系？
5. 单引号和双引号分别用于什么？
6. `\n` 中的反斜杠和字母 `n` 合起来表示什么？
7. `endl` 和 `\n` 都能完成什么？为什么竞赛程序更常用 `\n`？
8. `scanf` 和 `printf` 分别负责什么？输入变量前的 `&` 有什么作用？
9. `int`、`long long`、`double` 输入时分别使用什么格式符？
10. `%.2f` 和 `%02d` 分别会怎样控制输出？
11. 为什么 OI 程序通常不输出“请输入……”？
12. 计数器和累加器有什么区别？
13. 为什么它们通常从 0 开始？
14. `17 / 5` 和 `17 % 5` 分别是多少、各表示什么？
15. 怎样取得一个正整数的个位？
16. 为什么计算平均数时经常除以 `3.0` 而不是 `3`？
