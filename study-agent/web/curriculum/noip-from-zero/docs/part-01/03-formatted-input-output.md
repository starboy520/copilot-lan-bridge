# 第 3 章 格式化输入和输出

第 1 章已经使用过 `cin` 和 `cout`。这一章按照学校课程，再学习另一组常用的输入输出工具：

- `scanf`：按照指定格式读入数据；
- `printf`：按照指定格式输出数据。

它们的名字可以先这样记：`scan` 有“读取”的意思，`print` 有“打印”的意思，结尾的 `f` 表示“按照格式”。`cin/cout` 和 `scanf/printf` 都能写正确的 C++ 程序；初学时，同一个程序尽量选一组使用，不要来回混用。

---

## 3.1 第一次使用 `scanf`

下面的程序读入一个整数年龄：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int age;
    scanf("%d", &age);
    printf("%d\n", age);
    return 0;
}
```

如果输入：

```text
13
```

程序就会输出：

```text
13
```

先把输入语句拆开看：

```cpp
scanf("%d", &age);
```

- `scanf`：调用格式化输入工具；
- 圆括号 `()`：里面放要交给 `scanf` 的内容；
- `"%d"`：告诉程序“接下来要读一个 `int` 整数”；
- 逗号 `,`：把格式和变量分开；
- `&age`：告诉 `scanf`，读到的整数要放进变量 `age` 的位置；
- 分号 `;`：这条语句结束。

### 为什么变量前面有 `&`

可以继续把变量想象成一个有名字的小盒子。`age` 是盒子的名字，`&age` 可以暂时理解为“找到 `age` 这个盒子的位置”。`scanf` 必须知道位置，才能把读到的数据放进去。

现阶段按下面的规则使用即可：

```cpp
scanf("%d", &age);    // 输入变量前要写 &
printf("%d\n", age); // 输出变量前不要写 &
```

以后学习指针时，我们会更完整地解释 `&`。这里的 `&` 不是英文单词 `and`，也不是让两个数相加。

## 3.2 格式符：数据的“座位牌”

`%d` 叫作**格式符**。它像一张座位牌，告诉 `scanf` 或 `printf`：这个位置应该放哪种数据。

| 数据类型 | `scanf` 输入 | `printf` 输出 | 示例变量 |
|---|---|---|---|
| `int` | `%d` | `%d` | `int age;` |
| `long long` | `%lld` | `%lld` | `long long population;` |
| `double` | `%lf` | `%f` | `double price;` |
| `char` | `%c` | `%c` | `char grade;` |

这里最容易弄错的是 `double`：

```cpp
double price;
scanf("%lf", &price);  // 输入 double 使用 %lf
printf("%f\n", price); // 输出 double 使用 %f
```

请把它记成一对：**输入 `double` 用 `%lf`，输出 `double` 用 `%f`。**

格式符写在双引号里面。第 5 章还会学习写在双引号外面的 `%` 运算符，它表示取余，两者位置和作用都不同。

### 一次输入多个数据

```cpp
int a, b, c;
scanf("%d%d%d", &a, &b, &c);
```

三个 `%d` 从左到右分别对应 `a`、`b`、`c`。以下两种输入都能正确读取：

```text
10 20 30
```

```text
10
20
30
```

读取数字时，空格和换行通常都可以分隔数据。格式符的数量、类型和后面的变量必须一一对应，顺序也不能交换。

```cpp
int age;
double height;
scanf("%d%lf", &age, &height);
```

这里第一个数据进入 `age`，第二个数据进入 `height`。

### 输入中带有固定符号

如果题目规定时间写成 `时:分`，中间必须有冒号：

```cpp
int hour, minute;
scanf("%d:%d", &hour, &minute);
```

这时输入应当像：

```text
8:05
```

双引号中的冒号要求输入中也出现冒号。普通 OI 题大多使用空格或换行分隔数据，一定要以题目的输入格式为准。

### 读取字符时的小空格

`%c` 会读取下一个字符，空格和换行也算字符。如果前面刚读过数字，可以在 `%c` 前放一个空格，让 `scanf` 先跳过空白：

```cpp
char grade;
scanf(" %c", &grade);
```

这是读取字符时的常用写法。现阶段练习主要读取数字，不要求马上熟练掌握它。

## 3.3 使用 `printf` 组合输出

```cpp
int a = 12;
int b = 8;
printf("%d + %d = %d\n", a, b, a + b);
```

输出：

```text
12 + 8 = 20
```

执行时：

1. 第一个 `%d` 放入 `a` 的值；
2. 第二个 `%d` 放入 `b` 的值；
3. 第三个 `%d` 放入 `a + b` 的结果；
4. 其他文字、空格和符号原样输出；
5. `\n` 表示换行。

可以把双引号中的内容看作一张“输出模板”，后面的数据按顺序坐进格式符的位置。

### 输出空格和换行

```cpp
printf("%d %d\n", a, b);
```

两个 `%d` 中间有一个空格，因此两个数字之间也会有一个空格。结尾的 `\n` 负责换行。

OI 评测会严格比较输出。下面两种结果看起来相近，但第一种缺少空格：

```text
128
12 8
```

### 输出一个百分号

因为 `%` 用来开始一个格式符，如果真的要输出百分号，需要写两个 `%`：

```cpp
printf("完成度：80%%\n");
```

输出：

```text
完成度：80%
```

## 3.4 控制小数位数

题目经常要求“保留两位小数”。在 `printf` 中，可以这样写：

```cpp
double price = 12.5;
printf("%.2f\n", price);
```

输出：

```text
12.50
```

`%.2f` 可以拆开理解：

- `%`：格式符开始；
- `.2`：小数点后保留 2 位；
- `f`：输出小数。

再看两个例子：

```cpp
double x = 3.14159;
double y = 2.71828;
printf("%.2f\n", x);
printf("%.3f\n", y);
```

输出：

```text
3.14
2.718
```

`printf` 会按照要求进行四舍五入。`%.1f` 表示保留 1 位小数，`%.3f` 表示保留 3 位小数。

注意：`scanf` 输入 `double` 使用 `%lf`，但 `printf` 输出并保留两位小数使用 `%.2f`。

## 3.5 控制整数宽度

### 不足位置时补空格

```cpp
printf("%5d\n", 42);
```

`%5d` 表示这个整数至少占 5 个位置。`42` 只需要 2 个位置，所以左边补 3 个空格。

为了看清空格，下面用小圆点代替空格展示效果，程序实际不会输出小圆点：

```text
···42
```

如果数字本身超过 5 位，`printf` 会完整输出，不会把数字截断。

### 不足位置时补 `0`

电子钟常把 8 点 5 分显示为 `08:05`：

```cpp
int hour = 8;
int minute = 5;
printf("%02d:%02d\n", hour, minute);
```

`%02d` 表示整数至少占 2 个位置，不足时在左边补 `0`。输出为：

```text
08:05
```

## 3.6 计算平均数时的类型问题

输入三个整数成绩，输出平均分，保留一位小数：

```cpp
int a, b, c;
scanf("%d%d%d", &a, &b, &c);
double average = (a + b + c) / 3.0;
printf("%.1f\n", average);
```

为什么除数写成 `3.0`，而不是 `3`？

如果参与除法的两个数都是整数，C++ 会进行整数除法，小数部分会被舍去：

```cpp
printf("%d\n", 5 / 2);       // 输出 2
printf("%.1f\n", 5 / 2.0);  // 输出 2.5
```

需要小数结果时，要让除法中至少有一个数是小数类型。现阶段统一使用 `/ 3.0`，意思直观，也不会引入新的语法。

## 3.7 完整例题：购物小票

### 题目

一本练习册单价为 `price` 元，购买 `count` 本。输入单价和数量，输出总价，保留两位小数。

#### 样例输入

```text
8.5 3
```

#### 样例输出

```text
25.50
```

### 分析

```text
输入：单价 price、数量 count
处理：total = price × count
输出：total，保留两位小数
```

### 程序

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    double price;
    int count;
    scanf("%lf%d", &price, &count);

    double total = price * count;
    printf("%.2f\n", total);
    return 0;
}
```

这里的格式对应关系是：

| 数据 | 类型 | 输入格式 | 输出格式 |
|---|---|---|---|
| `price` | `double` | `%lf` | 本题不直接输出 |
| `count` | `int` | `%d` | 本题不直接输出 |
| `total` | `double` | 本题不输入 | `%.2f` |

### 自己测试

至少测试：

- `8.5 3`：普通小数；
- `10 1`：整数形式的单价；
- `0.25 4`：结果正好为 1；
- `99.99 0`：数量为 0。

## 3.8 常见错误检查表

### 错误 1：忘记输入变量前的 `&`

```cpp
scanf("%d", age);  // 错误
```

应改为：

```cpp
scanf("%d", &age);
```

### 错误 2：`double` 输入格式写错

```cpp
double price;
scanf("%f", &price);  // 错误：输入 double 应使用 %lf
```

正确写法：

```cpp
scanf("%lf", &price);
```

### 错误 3：格式符和变量数量不同

```cpp
int a, b;
scanf("%d", &a, &b);  // 只有一个 %d，却给了两个变量
```

正确写法：

```cpp
scanf("%d%d", &a, &b);
```

### 错误 4：在 OI 输出中加入提示语

```cpp
printf("请输入两个整数：");
```

除非题目明确要求，否则不要输出这类提示语。评测系统只接受题目规定的结果格式。

### 关于 `string`

本章的 `scanf` 练习只输入整数、小数和字符。C++ 的 `string` 不能直接配合上表中的格式符使用；遇到姓名等 `string` 输入时，现阶段继续使用第 2 章的 `cin >> name`。不要在同一个初学程序里混用两组输入方式。

## 第 3 章练习

### 基础练习 1：三数输出

使用 `scanf` 输入三个整数，再使用 `printf` 按照“第一个数、一个空格、第二个数、一个空格、第三个数”的格式输出。

### 基础练习 2：圆的周长

输入半径 `r`，使用 `3.14159` 作为圆周率，输出圆的周长，保留两位小数。

### 提高练习 3：平均分

输入语文、数学、英语三科的整数成绩，输出平均分，保留一位小数。

### 提高练习 4：电子钟

输入小时和分钟两个整数，输出 `时:分`，小时和分钟都占两位，不足两位时在左边补 `0`。

样例输入：

```text
8 5
```

样例输出：

```text
08:05
```
