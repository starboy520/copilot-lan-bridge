# 从零开始学信奥

这是一套面向初中生的 C++ 与信息学竞赛（OI）入门教程。

当前教程以一名 **13 岁、C++ 零基础**的学习者为主要对象。内容强调循序渐进、亲手运行、用具体数据验证，以及在理解之后再进入竞赛训练。

## 适合谁

- 初一左右、第一次接触 C++ 的学生
- 希望为 CSP-J 和后续 NOIP 学习打基础的学生
- 希望陪孩子稳步学习的家长或老师

## 怎么使用

建议每次学习 60～75 分钟，一次只处理一个核心概念：

1. 先阅读生活化问题，口头说出“输入—处理—输出”。
2. 亲手输入并运行例题，不复制粘贴。
3. 运行前先预测结果，运行后核对。
4. 改变至少一个数据或要求，观察程序怎样变化。
5. 独立完成练习，再查看答案。
6. 达到章末闯关标准后再进入下一章。

## 长期路线

教程将逐步扩展为完整的零基础信奥学习路径：

- 第一部分：简单程序、数据与基本运算（已完成）
- 第二部分：条件判断与分支结构
- 第三部分：循环结构与基础枚举
- 第四部分：数组、字符串与函数
- 第五部分：模拟、排序与复杂度
- 第六部分：前缀和、二分与基础数据结构
- 第七部分：递归、DFS 与 BFS
- 第八部分：贪心与动态规划入门
- 第九部分：树、图与并查集基础
- 第十部分：CSP-J 专题训练、模拟赛与复盘

后续部分会根据实际学习反馈调整难度和节奏，不机械追赶章节数量。

## 编写原则

- 不把大学教材简单缩短后交给孩子
- 新知识必须有具体用途和可运行示例
- 一章只形成一段平缓的难度坡度
- 练习分为基础、提高和挑战
- 先学会解释思路，再追求模板和速度
- 报错是调试线索，不是失败证明
