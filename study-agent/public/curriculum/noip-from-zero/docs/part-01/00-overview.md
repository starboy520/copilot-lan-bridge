# 第一部分：走进 C++ 与信息学竞赛

> 适合对象：13 岁、C++ 零基础学生  
> 建议课时：12～15 课时，每课 60～75 分钟  
> 学习目标：从第一次运行程序开始，学会用 C++ 读取数据、计算并按要求输出结果。

---

## 写给学习者的话

你好！从这一页开始，你将学习怎样把自己的想法变成程序。

刚开始时，你可能会遇到英文单词、奇怪的符号和红色的报错信息。这非常正常。程序员并不是从不出错的人，而是能根据线索一步一步找到错误的人。

学习时请记住三句话：

1. 代码一定要亲手输入、运行和修改。
2. 看懂例题不等于会做，合上例题再写一次才算真正学会。
3. 遇到问题先用具体数字在纸上算一遍，再考虑怎样让计算机来做。

这一部分不会追求难题。我们的目标是稳稳地迈出第一步。

---

## 本部分学习地图

| 章节 | 主要内容 | 完成后的能力 |
|---|---|---|
| 第 1 章 | 简单程序与 OI | 会运行、修改和提交第一个程序 |
| 第 2 章 | 基础数据类型 | 会用变量保存整数、小数、字符和文字 |
| 第 3 章 | 格式化输入和输出 | 会按题目要求读入数据并准确输出 |
| 第 4 章 | 计数器与累加器 | 会统计次数、合计数量和更新变量 |
| 第 5 章 | 整数与取余 | 会解决分组、周期、时间和数位问题 |

每学完一小节，请完成三个动作：

- 预测：运行前先猜输出是什么；
- 验证：亲自运行程序；
- 改造：至少改变一个数据或要求，观察结果。
