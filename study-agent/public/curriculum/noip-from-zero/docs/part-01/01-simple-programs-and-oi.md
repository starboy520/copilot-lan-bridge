# 第 1 章 简单程序与 OI

## 1.1 什么是程序

计算机计算得很快，但它不会猜测我们的想法。我们必须把要做的事情写成清楚、准确、可以执行的指令。这些指令组成的整体就叫作**程序**。

例如，计算两件文具的总价，可以分成三步：

1. 得到第一件文具的价格；
2. 得到第二件文具的价格；
3. 把两个价格相加并告诉我们结果。

大多数入门程序都可以看成下面这个过程：

```text
输入数据  →  处理数据  →  输出结果
```

以“计算长方形面积”为例：

```text
输入：长和宽
处理：面积 = 长 × 宽
输出：面积
```

在写代码之前，先把题目说成这样的三步，常常会让问题变得简单很多。

### 想一想

计算三门课的平均分时：

- 输入是什么？
- 处理是什么？
- 输出是什么？

先口头回答，再继续阅读。

## 1.2 什么是 OI

**OI** 是 Olympiad in Informatics 的缩写，通常译作“信息学奥林匹克竞赛”。在 OI 中，我们主要做这样的事情：

1. 阅读题目，弄清要解决的问题；
2. 设计一套清楚而有效的解决步骤，这叫作**算法**；
3. 使用 C++ 等编程语言写出程序；
4. 把程序提交给评测系统；
5. 评测系统使用许多测试数据检查程序是否正确、是否足够快。

OI 不只是“学会 C++”。

- C++ 像我们使用的语言；
- 算法像解决问题的方法；
- 调试像根据线索检查自己的方法和表达；
- 比赛则要求我们在限定时间内把这些事情做好。

对刚开始学习的同学来说，现在最重要的不是比赛名次，而是逐渐学会：

> 把一个问题拆成清楚的小步骤，并让计算机准确执行。

### 常见竞赛名称

- **CSP-J**：入门级认证，适合初学者逐步挑战；
- **CSP-S**：提高级认证，对算法能力要求更高；
- **NOIP**：全国青少年信息学奥林匹克联赛。

我们现在从最基础的程序开始，为以后的 CSP-J 打地基。

## 1.3 第一个 C++ 程序

### 第一次上机：从代码到结果

不同学校使用的软件可能不同，按钮名称也可能叫“编译”“构建”“运行”或“编译并运行”，但基本过程相同：

```text
新建源文件 → 输入并保存代码 → 编译 → 运行 → 查看输出
```

第一次操作时，按照下面的步骤完成：

1. 打开学校指定的 C++ 编程软件或在线编程环境；
2. 新建一个 C++ 源文件，保存为 `hello.cpp`；
3. 亲手输入下面的代码，暂时不要复制粘贴；
4. 点击“编译”或“编译并运行”；
5. 如果出现红色报错，先核对英文标点和大小写；
6. 成功运行后，检查输出是否与教材完全相同。

文件名末尾的 `.cpp` 表示它是一份 C++ **源代码文件**。源代码是人写给计算机看的指令；**编译**会检查这些指令是否符合 C++ 语法，并把它们变成可以运行的程序；**运行**才是真正执行程序。

请亲手输入下面的代码：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, OI!" << endl;
    return 0;
}
```

运行后，屏幕上会显示：

```text
Hello, OI!
```

### 逐行认识代码

第一次看到时，不需要一次记住全部英文单词。先知道程序从 `main` 开始、`cout` 负责输出、`endl` 负责换行，就可以继续练习。

#### 第 1 行

```cpp
#include <iostream>
```

它告诉 C++：我们要使用输入和输出工具。现阶段可以把它理解为“取来输入输出工具箱”。

#### 第 2 行

```cpp
using namespace std;
```

这一行能让我们比较方便地使用 `cout`、`cin` 等工具。现在先按固定写法使用，以后再理解更深的含义。

#### 第 4 行

```cpp
int main() {
```

`main` 是程序开始执行的地方。左花括号 `{` 表示这一部分代码开始了。

#### 第 5 行

```cpp
cout << "Hello, OI!" << endl;
```

`cout` 用来输出内容。两个连续的小于号 `<<` 可以先理解成“把右边的内容送给 `cout`”。双引号中的文字会原样显示。`endl` 读作“end line”，表示输出到这里后换到下一行。

现在先把 `endl` 当作“换行”的固定写法。第 2 章认识字符后，我们会再学习竞赛中更常用的换行写法。

#### 第 6 行

```cpp
return 0;
```

它表示程序正常结束。

#### 第 7 行

```cpp
}
```

右花括号 `}` 与前面的左花括号配对，表示 `main` 中的内容结束。

### 必须留意的符号

C++ 对符号很认真：

- 英文分号 `;` 常表示一条语句结束；
- 英文双引号 `" "` 包围一段文字；
- 圆括号 `( )`、花括号 `{ }` 要成对出现；
- C++ 区分大小写，`cout` 不能写成 `Cout`；
- 代码中的标点通常要使用英文标点。

### 动手改造

把程序改成输出两行：

```text
My name is Xiaoming.
I am ready!
```

一种写法是：

```cpp
cout << "My name is Xiaoming." << endl;
cout << "I am ready!" << endl;
```

## 1.4 让程序做计算

我们可以直接让 `cout` 输出计算结果：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << 12 + 8 << endl;
    return 0;
}
```

输出是：

```text
20
```

请注意下面两行的区别：

```cpp
cout << 12 + 8 << endl;
cout << "12 + 8" << endl;
```

第一行输出计算结果 `20`；第二行把双引号里的内容当作普通文字，输出 `12 + 8`。

### 四种基本运算

| 运算 | C++ 符号 | 示例 | 结果 |
|---|---:|---:|---:|
| 加法 | `+` | `7 + 3` | `10` |
| 减法 | `-` | `7 - 3` | `4` |
| 乘法 | `*` | `7 * 3` | `21` |
| 除法 | `/` | `8 / 2` | `4` |

乘号必须写成 `*`，不能写成数学课本中的 `×`。

### 小心运算顺序

C++ 中的运算顺序与数学中的基本规则相似：先乘除，后加减；圆括号中的内容优先。

```cpp
cout << 2 + 3 * 4 << endl;       // 输出 14
cout << (2 + 3) * 4 << endl;     // 输出 20
```

`//` 后面的内容叫作**注释**，是写给人看的说明，不会被程序执行。

## 1.5 OI 题目的输入和输出

看一道最简单的 OI 题目。

### 先认识题目的六个部分

| 部分 | 它告诉我们什么 |
|---|---|
| 题目描述 | 需要解决什么问题 |
| 输入格式 | 会输入哪些数据、顺序是什么 |
| 输出格式 | 程序必须输出什么 |
| 数据范围 | 输入可能有多大，用来帮助选择数据类型和方法 |
| 样例输入 | 一组供我们理解和试运行的数据 |
| 样例输出 | 这组样例输入对应的正确结果 |

读题时不要只看样例。建议按“题目描述—输入—输出—数据范围”的顺序读完，再观察样例。

### 题目：两数之和

#### 题目描述

输入两个整数 `a` 和 `b`，输出它们的和。

#### 输入格式

一行两个整数，依次表示 `a` 和 `b`。

#### 输出格式

输出一个整数，表示 `a + b` 的结果。

#### 数据范围

`a` 和 `b` 都在负十亿到正十亿之间。

#### 样例输入

```text
12 8
```

#### 样例输出

```text
20
```

程序如下：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
```

暂时把这三行理解为：

```cpp
int a, b;          // 准备两个可以保存整数的变量
cin >> a >> b;     // 读入两个整数，分别放入 a 和 b
cout << a + b;     // 计算并输出它们的和
```

这里提前用到了 `int` 和变量，只要先知道它们能保存整数即可。逗号把变量名 `a` 和 `b` 分开；`cin` 后面的 `>>` 可以看成“把读到的数据依次放进右边的变量”。第 2 章会从“变量是什么”开始完整讲解。

### 为什么不能输出提示语

平时写小游戏时，我们可能会写：

```cpp
cout << "请输入两个整数：";
```

但在 OI 评测中，输出必须严格符合题目要求。如果正确答案应当只有：

```text
20
```

你的程序却输出：

```text
请输入两个整数：20
```

评测系统会认为答案错误。因此，竞赛程序通常不输出题目没有要求的提示语。

### 样例不是全部测试

程序通过样例，只能说明它对这一个例子给出了正确结果。评测系统还会使用其他数据，例如：

```text
0 0
```

```text
-5 9
```

```text
100000 200000
```

所以，我们不能把样例答案直接写进程序，而要写出能解决所有合法输入的方法。

### 自己设计测试数据

除了题目给出的样例，还要主动选择不同情况检查程序：

| 测试目的 | 输入 | 应当输出 |
|---|---|---|
| 普通正数 | `12 8` | `20` |
| 两个零 | `0 0` | `0` |
| 包含负数 | `-5 9` | `4` |
| 比样例更大的数 | `100000 200000` | `300000` |

运行程序之前先手算答案，再比较程序输出。这个习惯比反复盯着代码更容易发现错误。

## 1.6 五种常见结果

提交程序后，可能看到以下结果：

| 结果 | 常见缩写 | 含义 |
|---|---|---|
| 答案正确 | AC | 程序通过了测试 |
| 编译错误 | CE | 代码不符合 C++ 语法，未能生成程序 |
| 答案错误 | WA | 程序能运行，但某些结果不正确 |
| 运行错误 | RE | 程序运行时发生错误 |
| 超出时间 | TLE | 程序太慢，没有在规定时间内完成 |

现在遇到最多的通常是 CE 和 WA。

### 初学者检查清单

编译失败时，依次检查：

1. 分号是否漏写；
2. 引号、圆括号、花括号是否配对；
3. 是否误用了中文标点；
4. 单词大小写是否正确；
5. 报错提示最先指向哪一行。

答案错误时，依次检查：

1. 输入顺序是否理解正确；
2. 计算公式是否正确；
3. 输出是否多字、少字或少换行；
4. 能否自己设计几个小数据手算验证。

### 第一次调试实验

下面三段代码都存在问题。先不要看答案，亲手运行或观察，并判断会出现 CE、WA，还是正确结果。

#### 故障 1：少了什么符号

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello!" << endl
    return 0;
}
```

#### 故障 2：大小写正确吗

```cpp
#include <iostream>
using namespace std;

int main() {
    Cout << "Hello!" << endl;
    return 0;
}
```

#### 故障 3：为什么样例通过了，提交仍可能错误

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << 20 << endl;
    return 0;
}
```

第三段程序输入 `12 8` 时恰好输出 `20`。请再用 `1 2` 测试，看看它是否真的解决了“两数之和”。

## 1.7 本章词汇卡

| 词语 | 现在需要掌握的意思 |
|---|---|
| 源代码 | 人使用编程语言写出的指令，例如 `.cpp` 文件 |
| 编译 | 检查 C++ 语法，并把源代码变成可以运行的程序 |
| 运行 | 让计算机真正执行已经编译好的程序 |
| 输入 | 交给程序处理的数据 |
| 输出 | 程序处理后给出的结果 |
| 算法 | 解决问题的一组清楚步骤 |
| 评测 | 使用多组测试数据检查程序是否正确、是否足够快 |

## 第 1 章练习

### 热身练习 1：补全第一段程序

把两处横线分别替换成正确内容，让程序输出一行 `I can code!`。

```cpp
#include <iostream>
using namespace std;

int main() {
    ______ << "I can code!" << ______;
    return 0;
}
```

### 基础练习 2：认识输出

写程序输出：

```text
I love C++.
```

### 基础练习 3：小小计算器

直接用 `cout` 输出 `35 + 27` 的计算结果。

### 提高练习 4：长方形面积

输入长方形的长和宽，输出面积。

样例输入：

```text
6 4
```

样例输出：

```text
24
```

### 挑战练习 5：交换顺序输出

输入两个整数 `a`、`b`，先输出 `b`，再输出 `a`，中间用一个空格隔开。

样例输入：

```text
3 8
```

样例输出：

```text
8 3
```
